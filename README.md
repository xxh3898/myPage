# 🇹🇭 태국 여행 정보 사이트 (Thailand Travel Guide)

이 프로젝트는 태국 여행을 계획하는 분들을 위한 기본적인 정보를 제공하는 정적 웹사이트입니다. HTML과 CSS를 사용하여 태국의 주요 도시, 문화 예절, 그리고 대표 음식에 대한 정보를 소개합니다.

## ✨ 주요 기능

이 프로젝트는 다음과 같은 페이지로 구성되어 있습니다.

### 1. 메인 페이지 (`index.html`)
* 웹사이트의 홈 페이지로, 다른 주요 섹션으로 안내합니다.
* **네비게이션 바**: 도시별, 문화, 음식 페이지로 이동할 수 있습니다.
    * '도시별' 메뉴는 드롭다운 형태로 방콕, 치앙마이, 푸켓 등의 하위 페이지로 연결됩니다.
* **주요 콘텐츠**: 태국 여행의 매력을 소개하는 배너와 카테고리별(도시, 문화, 음식) 바로가기 링크를 제공합니다.
* **하단 정보**: 주태국 대한민국 대사관의 주소, 연락처, 웹사이트 등 필수 정보를 포함합니다.

### 2. 음식 소개 페이지 (`food.html`)
* 태국의 다양한 음식을 카테고리별로 소개합니다.
* **고정 네비게이션**: '식사', '간식', '과일' 카테고리로 빠르게 스크롤할 수 있는 좌측 고정 메뉴가 있습니다.
* **콘텐츠**: 팟타이, 똠얌꿍, 망고 스티키 라이스 등 대표 음식들의 사진과 설명을 카드 형태로 보여줍니다.

### 3. 문화 소개 페이지 (`culture.html`)
* 태국 여행 시 알아야 할 현지 문화와 예절을 안내합니다.
* **주요 예절**: '와이(Wai)' 인사법, 사원 방문 시 주의사항, 발 관련 예절, 왕실 존중 등 여행객이 주의해야 할 팁을 제공합니다.

## 🛠️ 사용 기술

* **`HTML5`**: 웹페이지의 구조와 콘텐츠를 담당합니다.
* **`CSS3`**: `style.css` 파일을 통해 웹사이트의 전체적인 디자인과 레이아웃(카드 정렬, 고정 메뉴 등)을 구현합니다.

## 💡 실행 방법

이 프로젝트는 정적 웹사이트이므로 별도의 서버 설치가 필요 없습니다.

1.  프로젝트를 로컬 환경에 다운로드하거나 Git을 사용하여 클론(clone)합니다.
2.  메인 파일인 `index.html`을 원하는 웹 브라우저(Chrome, Safari, Edge 등)에서 열기만 하면 됩니다.
